### 🧪 БЛОК 2: Математический и химический вычислительный движок

#### Задача 2.1: Калькулятор физико-химических и геометрических параметров таблетки
* **Что нужно сделать**: Создать вычислительный движок, рассчитывающий коэффициент Хауснера, индекс Карра, сыпучесть порошка, среднюю плотность смеси, геометрию заполнения матрицы пуансона (для таблеток, в т.ч. диаметром 3 мм / 0.3 см) и выход готовой продукции с экономикой.
* **С какими файлами работать**:
  - `[NEW] src/lib/calculator.ts`
* **Формулы для реализации**:
  - **Коэффициент Хауснера ($H$)**: $H = \rho_{\text{tapped}} / \rho_{\text{loose}}$
  - **Индекс Карра ($C$)**: $C = 100 \cdot (\rho_{\text{tapped}} - \rho_{\text{loose}}) / \rho_{\text{tapped}}$
  - **Классификация сыпучести по $H$**:
    - $H < 1.11$: "Отличная" (Excellent)
    - $1.12 \le H \le 1.18$: "Хорошая" (Good)
    - $1.19 \le H \le 1.25$: "Удовлетворительная" (Fair)
    - $1.26 \le H \le 1.34$: "Допустимая" (Passable)
    - $1.35 \le H \le 1.45$: "Плохая" (Poor)
    - $H \ge 1.46$: "Очень плохая" (Very Poor)
  - **Объем матрицы цилиндра ($V$)**: $V = \pi \cdot (d/2)^2 \cdot h$, где $d$ — диаметр пуансона, $h$ — глубина заполнения матрицы.
  - **Макс. масса смеси в matrix ($M_{\text{max}}$)**: $M_{\text{max}} = V \cdot \rho_{\text{loose\_blend}}$
  - **Рабочий вес таблетки ($M_{\text{work}}$)**: Рекомендуется $M_{\text{work}} \le 0.9 \cdot M_{\text{max}}$
  - **Количество таблеток из сырья ($N$)**: $N = M_{\text{active\_raw}} / (M_{\text{work}} \cdot \text{доля\_активного\_вещества})$
  - **Пористость таблетки (Porosity, $\varepsilon$)**: $\varepsilon = 1 - (\rho_{\text{apparent}} / \rho_{\text{true}})$, где $\rho_{\text{apparent}}$ — кажущаяся плотность таблетки (масса / геометрический объем), а $\rho_{\text{true}}$ — истинная плотность смеси.
* **Как должно быть в результате**:
  Экспортируются чистые функции:
  - `calculateFlowability(loose: number, tapped: number)` -> `{ hausner: number, carr: number, rating: string }`
  - `calculatePorosity(massMg: number, volumeCm3: number, trueDensityBlend: number)` -> `number`
  - `calculateBlendProperties(ingredients: { ingredient: Ingredient, percentage: number }[])` -> `{ looseDensity: number, tappedDensity: number, flowability: ... }`
  - `calculateTableting(diameterCm: number, depthCm: number, looseDensity: number)` -> `{ volume: number, maxWeightMg: number, recommendedWeightMg: number }`
  - `calculateBatch(activeRawWeightG: number, recommendedWeightMg: number, activePercentage: number, costPerKgBlend: number)` -> `{ totalTablets: number, totalBatchWeightKg: number, costPerTabletUsd: number, totalBatchCostUsd: number }`
  - `checkCompatibilityAndLimits(ingredients: { ingredient: Ingredient, percentage: number }[])` -> возвращает массив предупреждений о несовместимости и превышении лимитов `maxSafePercentage`.
* **Чек-лист выполнения**:
  - [x] Создан файл `src/lib/calculator.ts`
  - [x] Реализован расчет $H$, $C$ и вербальной шкалы сыпучести
  - [x] Реализовано взвешенное усреднение плотностей для смеси
  - [x] Реализованы геометрические расчеты цилиндрической матрицы
  - [x] Реализован расчет размера партии, количества таблеток и себестоимости
  - [x] Реализован алгоритм поиска перекрестных несовместимостей по `chemicalClassId` и превышений `maxSafePercentage`
