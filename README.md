# PharmNode Studio

> **B2B SaaS-платформа** для виртуального формулирования лекарственных форм и БАД.  
> Концепция — **Quality by Computational Design (QbCD)**: проверяй химическую совместимость и рассчитывай параметры таблетирования ещё до того, как войти в лабораторию.

---

## Зачем это нужно

Разработка таблетки или БАД — это не просто смешать ингредиенты. Технолог обязан:

- убедиться, что компоненты **химически совместимы** (иначе — реакция Майяра, окисление, деградация);
- рассчитать **физические свойства смеси**: сыпучесть, пористость, геометрию пресс-формы;
- оценить **стабильность** с точки зрения влажности, света, тепла;
- выбрать **упаковку** под условия хранения;
- сформировать **GMP-отчёт** для регулятора.

Всё это традиционно делается вручную или в Excel. PharmNode заменяет этот процесс визуальным No-Code конфигуратором с моментальным расчётом.

---

## Как это работает — шаг за шагом

### 1. Открываешь конфигуратор (`/configurator`)

На экране — **Canvas** (холст), слева — панель ингредиентов.

### 2. Перетаскиваешь ингредиенты на холст

Каждый ингредиент становится **нодой** (карточкой) — с именем, ролью (активное вещество, наполнитель, лубрикант и т. д.) и процентом ввода.

### 3. Платформа мгновенно:

- **Проверяет совместимость** — ищет конфликты между химическими классами ингредиентов. Например: амины + лактоза = реакция Майяра (ошибка). Итог — цветовая матрица (heatmap) и список предупреждений.
- **Рассчитывает параметры смеси** — коэффициент Хауснера, индекс Карра (сыпучесть), пористость таблетки.
- **Симулирует таблетирование** — объём матрицы пуансона, масса засыпки, рабочий вес.
- **Считает себестоимость** — стоимость одной таблетки и размер партии.
- **Рекомендует упаковку** — ALU/ALU блистер при высокой гигроскопичности, светонепроницаемая при светочувствительности, холодовая цепь при низкой температуре деградации.

### 4. Сохраняешь рецептуру

Состояние холста (ноды, связи, проценты) сохраняется в базе данных. Можно вернуться позже или поделиться.

### 5. Экспортируешь GMP-отчёт в PDF

Полный технологический расчёт в документ для регулятора.

## Ключевые фичи

### 🧪 Node-Based Canvas
Визуальный редактор рецептур в стиле n8n / Node-RED. Ноды соединяются SVG-линиями (Bezier curves). Drag-and-drop, реактивный пересчёт при каждом изменении.

### ⚗️ Матрица химической совместимости
- **35 химических классов** (амины, органические кислоты, стеараты, фосфаты, восстанавливающие сахара и др.)
- Детерминированная экспертная система — без нейросетей, без галлюцинаций
- Правила: `incompatible` / `synergy`, уровни `error` / `warning`
- Ключевые конфликты из базы: реакция Майяра (амины + лактоза), щелочная деградация (амины + стеарат Mg), окисление (Витамин C + фосфат Ca)
- Интерактивная heatmap матрица совместимости

### 📊 Физико-химические расчёты

| Параметр | Формула |
|---|---|
| Коэффициент Хауснера | `ρ_tap / ρ_bulk` |
| Индекс Карра (%) | `(ρ_tap − ρ_bulk) / ρ_tap × 100` |
| Пористость таблетки | `1 − (ρ_bulk / ρ_true)` |
| Объём матрицы | геометрия пунсона (диаметр, высота) |
| Масса засыпки | из объёма матрицы и плотности смеси |

### 💊 Симуляция таблетирования
Параметры пресса, рабочий вес таблетки, геометрия матрицы — всё рассчитывается автоматически на основе свойств ингредиентов.

### 💰 Экономические расчёты
Себестоимость одной таблетки и производственной партии — с учётом цены каждого ингредиента ($/кг) и его доли в рецептуре.

### 📦 Рекомендации по упаковке
Детерминированный алгоритм: если гигроскопичность > 70 → ALU/ALU блистер; если светочувствительный → светонепроницаемая упаковка; если температура деградации < 40°C → хранение 2–8°C.

### 📄 GMP-отчёт в PDF
Полный технологический расчёт для регулятора: состав рецептуры, результаты совместимости, физические параметры, рекомендации.

### 🌙 Тёмная и светлая темы
- **Светлая**: строгий медицинский стиль — `#f8fafc` фон, `#005eb8` акцент
- **Тёмная**: премиум тёмная — `#000000` фон, `#05e69f` акцент

### 🔒 Авторизация и тарифы
OAuth через Google и GitHub (NextAuth.js). Тариф хранится на пользователе, лимиты проверяются на сервере.

## Архитектура

### Экспертная система (без ИИ в ядре)

Логика совместимости полностью детерминированная:

```
Ингредиенты → Химические классы → Матрица правил → Скоринг → Результат
```

Это сделано намеренно: **100% объяснимость** каждого решения, никаких галлюцинаций, упрощённое прохождение FDA/GMP проверок.

**Скоринговая формула:**
```
score = benefit × 0.4 + stability × 0.2 + manufacturability × 0.2 − risk × 0.2
```

## База знаний

Каждый ингредиент в системе описан несколькими слоями данных:

- **Физические свойства** — насыпная плотность, утряска плотность, размер частиц
- **Stability Profile** — pH, гигроскопичность (0–100), светочувствительность, температура деградации (°C)
- **Regulatory Info** — стандарт качества (USP-NF, EP, BP, JP), аллерген (Lactose, Gluten, Soy)
- **Эффекты** — матрица влияния на здоровье (иммунитет, энергия, сон, стресс)
- **Синергии** — усиление эффектов при комбинировании
- **Противопоказания** — ограничения (беременность, гипертония, диабет)

## Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/your-org/pharmnode.git
cd pharmnode

# Установить зависимости
npm install

# Настроить окружение
cp .env.example .env.local
# Заполнить DATABASE_URL, NEXTAUTH_SECRET, STRIPE_API_KEY и др.

# Применить миграции БД
npx prisma migrate dev

# Запустить dev-сервер
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

### Переменные окружения

| Переменная | Описание |
|---|---|
| `DATABASE_URL` | PostgreSQL строка подключения (Neon / Supabase) |
| `NEXTAUTH_SECRET` | Секрет для шифрования сессий |
| `NEXTAUTH_URL` | Публичный домен приложения |
| `STRIPE_API_KEY` | Ключ Stripe |
| `STRIPE_WEBHOOK_SECRET` | Webhook секрет Stripe |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | OAuth Google |
| `GITHUB_ID` / `GITHUB_SECRET` | OAuth GitHub |

## Важные оговорки

> PharmNode — **инструмент поддержки принятия решений**, а не замена лабораторных исследований.  
> Все расчёты носят информационный характер. Финальное решение всегда принимает квалифицированный технолог.  
> Платформа не создаёт лекарство автоматически — она формирует отчёт, который передаётся исследователям для дальнейшей лабораторной валидации, доклинических и клинических испытаний.
