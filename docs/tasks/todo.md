# Текущие задачи PharmNode — Развитие продукта

## Инструкции для AI-агента:
> **Контекст**: Развитие PharmNode от визуализатора рецептур до полноценного B2B-инструмента для создания БАДов (рынки США и ЕС).
> **Критические правила**:
> 1. Все типы — в [`src/types/pharm.ts`](../../src/types/pharm.ts). Не создавать локальных интерфейсов.
> 2. Вся бизнес-логика расчётов — в [`src/lib/calculator.ts`](../../src/lib/calculator.ts). Не дублировать формулы в компонентах.
> 3. Правила совместимости — в [`src/lib/chemicalRules.ts`](../../src/lib/chemicalRules.ts).
> 4. Стейт холста — в [`src/hooks/useNodeEditor.ts`](../../src/hooks/useNodeEditor.ts).
> 5. Никаких `any`. Точность расчётов — до 4 знаков после запятой.
> 6. Перед реализацией новой фичи — прочитать соответствующий SKILL.md.
> 7. Все новые фичи обязательно покрыть автоматическими тестами.
> 8. Интерактивные компоненты → `"use client"` директива.
> 9. CSS переменные тем — в [`src/app/globals.css`](../../src/app/globals.css). Не хардкодить цвета.

## Блок 1: Настройка дополнительных OAuth-провайдеров (Outlook, Facebook, LinkedIn)

> **Цель**: Получить и прописать ключи доступа для новых способов входа в систему, а также провести ручное тестирование.

### Задача 1.1: Регистрация приложений на платформах разработчиков и получение Client ID / Client Secret
- [ ] **Microsoft Azure Portal (для Outlook/Microsoft аккаунтов)**:
  - Зарегистрировать новое приложение в разделе **Azure Active Directory** (или Microsoft Entra ID).
  - Настроить тип аккаунтов (например, "Личные учетные записи Microsoft").
  - Добавить Redirect URI: `https://<ваш_домен>/api/auth/callback/azure-ad` (для локальной разработки: `http://localhost:3000/api/auth/callback/azure-ad`).
  - Создать новый секрет клиента в разделе **Certificates & secrets** и скопировать его значение.
- [ ] **Meta (Facebook) for Developers**:
  - Создать новое приложение типа **Consumer** или **Business**.
  - Добавить продукт **Facebook Login**, настроить Web Redirect URI: `https://<ваш_домен>/api/auth/callback/facebook`.
  - Скопировать **App ID** и **App Secret**.
- [ ] **LinkedIn Developer Portal**:
  - Создать приложение, привязать компанию.
  - Включить продукт **Sign In with LinkedIn**.
  - Настроить Authorized Redirect URLs: `https://<ваш_домен>/api/auth/callback/linkedin`.
  - Скопировать **Client ID** и **Client Secret**.

### Задача 1.2: Добавление ключей в переменные окружения
- [ ] Добавить в локальный файл `.env.local` (а также в настройки продакшена на Vercel или другом хостинге) следующие переменные:
  ```bash

  # Outlook / Microsoft
  AZURE_AD_CLIENT_ID="полученный_client_id"
  AZURE_AD_CLIENT_SECRET="полученный_client_secret"
  AZURE_AD_TENANT_ID="common" # или конкретный ID тенанта

  # Facebook
  FACEBOOK_CLIENT_ID="полученный_app_id"
  FACEBOOK_CLIENT_SECRET="полученный_app_secret"

  # LinkedIn
  LINKEDIN_CLIENT_ID="полученный_client_id"
  LINKEDIN_CLIENT_SECRET="полученный_client_secret"
  ```

### Задача 1.3: Ручное тестирование
- [ ] Запустить локальный сервер разработки `npm run dev`.
- [ ] Открыть страницу авторизации `http://localhost:3000/login`.
- [ ] Убедиться, что новые кнопки отображаются и имеют корректные подписи на русском и английском языках (при смене локали).
- [ ] Нажать на каждую из кнопок и проверить, что происходит редирект на соответствующую страницу авторизации (Microsoft, Facebook, LinkedIn).
