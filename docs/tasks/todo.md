# Текущие задачи PharmNode (GEO & SEO Optimization)

## Инструкции для AI-агента:
> **Контекст**: Оптимизация платформы под поисковые ответы генеративных сетей (LLM/RAG) и классическое SEO, базируясь на требованиях из `aires.md`.
> **Критические правила**:
> 1. Строгое следование принципам Generative Engine Optimization (GEO).
> 2. Фокус на Answer-First подход, семантическую разметку и высокую фактологическую плотность.

---

## 🎯 Спринт: Генеративное SEO (GEO) и расширение контента

### 1. [x] Подготовка инфраструктуры (SSG & Crawler Access)
- [x] **SSG для лендингов:** Убедиться, что главная страница и все новые публичные страницы рендерятся на сервере (Next.js App Router RSC / SSG). Исключить клиентский рендеринг (CSR) для важного контента (убрать загрузку текста через `useEffect`).
- [x] **Настройка `robots.txt`:** Создать/обновить `src/app/robots.ts`. Разрешить сканирование для ИИ-ботов (`OAI-SearchBot`, `Claude-SearchBot`, `PerplexityBot`, `ChatGPT-User`). Не блокировать `GPTBot` и `ClaudeBot` .
- [x] **Доступность документации:** Проверить, что техническая база знаний, API-документация и примеры не скрыты за авторизацией (NextAuth) или Paywall-ом, чтобы краулеры имели к ним полный доступ.

### 2. [x] Создание специализированных SEO-страниц
*Задача: Главный лендинг остается витриной с лаконичными блоками. В каждый блок добавляется кнопка "Узнать больше" (или аналогичная), ведущая на отдельную страницу. Эти новые страницы должны содержать развернутый LLM-SEO текст (без воды, с фактами и таблицами).*

- [x] **Обязательные страницы (из ТЗ):**
  - [x] `/features` — Развернутое описание функционала (Node-Based UI, матрицы, расчёты).
  - [x] `/workflow` — Детальное описание процесса работы (от выбора ингредиентов до экспорта рецептуры).
  - [x] `/about` — О нас (миссия, команда, фокус на B2B-фармацевтике).
  - [x] `/use-cases` — Примеры использования (R&D лаборатории, контрактное производство, стартапы).
  - [x] `/technologies` — Под капотом (используемые алгоритмы Хауснера/Карра, математика пористости, стек).
  - [x] `/regulatory` — Регуляторное соответствие (подготовка к FDA/EMA, экспорт в eCTD).
  - [x] `/pricing` — Подробный разбор тарифов (Hobby vs Professional, лимиты на ингредиенты).
- [x] **Дополнительные рекомендуемые страницы (База знаний / Словарь):**
  - [x] `/knowledge-base/compatibility-matrix` — Глубокий разбор того, как работают правила химической совместимости на платформе.
  - [x] `/knowledge-base/excipients` — Справочник вспомогательных веществ и их ролей (связующие, разрыхлители и т.д.).
  - [x] `/api-reference` — Описание публичного API (если планируется), форматы ответов, тайминги.
- [x] **Обновление Landing Page:** Добавить кнопки-переходы на все вышеуказанные страницы.

### 5. [x] Верстка и контентная оптимизация (по правилам GEO)
- [x] **Семантические таблицы:** Переписать все сравнения (особенно тарифы и фичи) с использованием строгих `<table>`. ИИ-парсеры лучше читают бинарные матрицы (Да/Нет) из таблиц, чем из div/flex.
- [x] **Answer-First:** На всех новых страницах под заголовками `H2`/`H3` размещать прямой ответ или определение (40-60 слов).
- [x] **Passage Independence:** Сделать каждый абзац самодостаточным по смыслу.
- [x] **Фактологическая плотность:** Удалить маркетинговую "воду" ("самая лучшая платформа"). Заменить на твердые факты: "точность вычислений до 4 знаков", "встроенные алгоритмы Хауснера", "ограничение 3 ингредиента на Hobby".

### 6. [x] Оптимизация главной страницы (Landing Page SEO & UX)
*Задача: Главная страница должна оставаться быстрой, вызывать доверие у поисковиков (E-E-A-T) и плавно переводить пользователя на глубокие SEO-страницы.*

- [x] **Семантический HTML5:** Убедиться в строгом использовании тегов `<main>`, `<section>`, `<article>`, `<header>`, `<footer>` вместо обезличенных `<div>`.
- [x] **E-E-A-T (Доверие и Экспертность):** Добавить блок с логотипами (клиентов/партнеров) и бейджи соответствия отраслевым стандартам (например, "eCTD Ready").
- [x] **Скорость и Core Web Vitals:** Оптимизировать LCP (задать `priority={true}` для главного изображения на первом экране) и включить Lazy Loading для всего остального.
- [x] **Метатеги:** Настроить выверенные `title` и `description` с использованием ключевых терминов (B2B SaaS, фармацевтические расчеты, Node-Based UI, рецептуры).
- [x] **Связка с SEO-страницами:** Проверить, что каждый смысловой блок лендинга завершается четкой кнопкой/ссылкой (например, "Узнать подробнее"), ведущей на специализированные страницы из пункта 2.
