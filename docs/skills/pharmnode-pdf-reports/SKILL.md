# PharmNode PDF Reports Generation Skill

## Общие требования к отчетам

Все генерируемые PDF-отчеты (например, валидационные GMP отчеты) должны быть профессионально оформлены, структурированы и соответствовать требованиям фармацевтического комплаенса.

### 1. Форматирование документа
- **Размер страницы:** стандартный A4 (`portrait`, `210x297` мм).
- **Поля (Margins):** левое/правое поле — не менее `20` мм. Верхнее/нижнее поле — не менее `20` мм.
- **Шрифты и иерархия:**
  - Заголовки разделов: `helvetica bold`, размер `10–12` pt, цвет — фирменный синий (`#005eb8`).
  - Текст таблиц и описания: `helvetica normal`, размер `8–9` pt, цвет — темно-серый (`#0f172a`).
  - Мелкий шрифт / дисклеймеры: `helvetica italic`, размер `6–7` pt, цвет — серый (`#64748b`).

### 2. Динамический перенос страниц (Page Breaks)
Для предотвращения наложения текста или обрезки внизу страницы необходимо отслеживать текущую y-координату (`y`) и принудительно переносить контент на новую страницу, если он превышает границу `270` мм:
```typescript
function checkPageBreak(amount: number) {
  if (y + amount > 270) {
    doc.addPage();
    y = 20; // Сброс y на новой странице
  }
}
```

### 3. Обязательные разделы отчета
- **Шапка (Header):** Логотип PharmNode, название отчета (GMP Validation Report), метаданные (Дата, Технолог, Регуляторный стандарт, Report ID).
- **Рецептура (Formulation Recipe):** Таблица со списком активных компонентов и вспомогательных веществ (CAS-номер, роль, процентное содержание, стоимость).
- **Свойства смеси (Powder Blend & Compaction Stats):** Насыпная и тапированная плотности, коэффициенты Хауснера и Карра, оценка сыпучести, диаметр пуансона, глубина заполнения матрицы, пористость таблетки.
- **Оболочка и органолептика (Coating & Organoleptic Additives):**
  - Вывод используемых или рекомендуемых компонентов для оболочки (например, HPMC, PVA, Opadry II) с указанием их функциональной роли (пленкообразователь, пластификатор, влагозащитный барьер).
  - Вывод органолептических корригентов (подсластители, ароматизаторы, красители) и их функциональной роли (маскировка вкуса/запаха, идентификация).
- **Аудит безопасности и предупреждения (Warnings & Compliance):** Список конфликтов совместимости, превышений безопасных дозировок, аллергенов.
- **Дисклеймер (Disclaimer):** Официальное уведомление об ограничении ответственности и необходимости лабораторного тестирования.
- **Блок подписей (Sign-off Block):** Поля для подписи технолога и QA-валидатора.
