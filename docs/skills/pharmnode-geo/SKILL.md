# Generative Engine Optimization (GEO) для PharmNode

Эпоха «10 синих ссылок» завершается, поисковики переходят к модели **«AI-ответчик и агент»** (Zero-Click поиск). Этот скил описывает строгие правила того, как должен быть организован контент и инфраструктура в проекте, чтобы платформу эффективно рекомендовали LLM-агенты (Gemini, ChatGPT, Perplexity, AI Overviews).

Всегда сверяйтесь с этим файлом при создании новых публичных страниц, компонентов для маркетинга и документации.

## 1. Инфраструктура и технический слой (App Router)

- **`robots.txt`**: 
  - ВСЕГДА разрешайте доступ краулерам поисковых ИИ (`OAI-SearchBot`, `Claude-SearchBot`, `PerplexityBot`, `ChatGPT-User`) в `src/app/robots.ts`.
  - При необходимости блокируйте краулеры обучения моделей (`GPTBot`, `ClaudeBot`).
- **`llms.txt`**:
  - Поддерживайте `public/llms.txt` (или `src/app/llms.txt/route.ts`). 
  - Он должен содержать краткое позиционирование (B2B SaaS для расчетов в фармацевтике), ссылки на тарифы, открытую документацию.
- **Рендеринг**:
  - Публичные страницы (лендинги, блог, документация) ОБЯЗАНЫ рендериться на сервере (React Server Components, SSR/SSG).
  - ЗАПРЕЩАЕТСЯ выводить основной текстовый контент через `useEffect` на клиенте.

## 2. Расширенная микроразметка (Schema.org / JSON-LD)

AI-боты ленивы. Им проще прочитать структурированный код, чем парсить текст. Интегрируйте JSON-LD на все публичные страницы:

- **`Organization`** (Глобально): Поле `sameAs` со ссылками на профили (LinkedIn, Crunchbase и т.д.) для построения графа сущности бренда.
- **`SoftwareApplication`** (Лендинги): Разметка продукта, тарифов (`offers`) и рейтинга.
- **`FAQPage`**: Размечайте блоки вопросов и ответов для прямого цитирования лимитов тарифов.
- **`HowTo` / `Article`**: Для инструкций и базы знаний. Добавляйте `Author Schema`, чтобы связывать контент с реальными экспертами.

## 3. Верстка и структура контента (Answer-First & Tables)

- **Без «воды» на старте**: Убирайте длинные вступления. Первые два абзаца должны содержать четкий, структурированный ответ на интент пользователя. AI-движки берут в цитаты только концентрированную суть.
- **Answer-First**: В инфо-статьях сразу под `H2`/`H3` размещайте прямой лаконичный ответ (40-60 слов).
- **Таблицы (`<table>`)**: Сравнения тарифов/алгоритмов верстайте через нативные HTML-таблицы, а не `div`. LLM извлекают факты из таблиц намного эффективнее.

## 4. Контентная стратегия и Information Gain

- **Уникальная ценность (Information Gain)**: У Google есть патент на "добавочную ценность". Если страница на 95% состоит из того, что уже есть в сети — она не ранжируется. Требуются: *новые факты, свежая статистика, реальный опыт, кейсы, живые скриншоты, раскрытие подводных камней*.
- **Отказ от AI-генерата**: Стратегия массового создания дешевых SEO-статей мертва. Контент должен писать или жестко модерировать эксперт.
- **Фактологическая плотность**: Исключайте размытый маркетинг. Упоминайте точность расчетов (4 знака), алгоритмы (Хауснер, Карр).

## 5. Коммерческая воронка и Omnichannel

- **Максимальная проработка коммерческих страниц**: Трафик смещается в коммерцию. Посадочные страницы должны иметь всё для принятия решения: цены, точные сроки, отзывы, гарантии, кому продукт *не* подходит, и удобную форму заявки.
- **Перестройка инфо-страниц**: Инфо-статьи не должны висеть в вакууме. Каждая статья должна вести к следующему шагу (переход в Node-Based UI, расчет на калькуляторе, заявка).
- **Внешнее присутствие (UGC и Бренд)**: Поисковики выводят в топ треды с Reddit, Quora и форумов. Бренд PharmNode должен развиваться омниканально (YouTube, Telegram, профильные форумы). Упоминания бренда на авторитетных независимых площадках — ключ к рекомендациям от AI.
