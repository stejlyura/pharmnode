# PharmNode Technological Processes Skill

## Влажная грануляция (Wet Granulation)

Пошаговые расчеты масс для влажной грануляции проводятся на основе целевого веса таблетки ($W_{tablet}$), количества таблеток в серии ($N_{tablets}$), процента АФИ ($API\%$), интрагранулярной доли ($Intra\%$), процента влажности сухих гранул ($LOD\%$), процента добавленного связующего раствора ($Liquid\%$) и процента технологических потерь ($Loss\%$).

### 1. Расчет сухих масс серии
- **Общая сухая масса серии ($kg$):**
  $$M_{dry} = \frac{W_{tablet} \times N_{tablets}}{10^6}$$
- **Чистая масса АФИ ($kg$):**
  $$M_{api} = M_{dry} \times \frac{API\%}{100}$$
- **Сухая масса интрагранулярной фазы ($kg$):**
  $$M_{intra\_dry} = M_{dry} \times \frac{Intra\%}{100}$$
- **Сухая масса экстрагранулярной фазы ($kg$):**
  $$M_{extra\_dry} = M_{dry} \times \frac{Extra\%}{100}$$
  где $Extra\% = 100\% - Intra\%$

### 2. Расчет массы влажного замеса перед сушкой
- **Масса влажной массы ($kg$):**
  $$M_{wet} = M_{intra\_dry} \times \left(1 + \frac{Liquid\%}{100}\right)$$

### 3. Расчет массы сырого заполнения матрицы ($FW$) с учетом LOD
Поскольку высушенный гранулят содержит остаточную влагу ($LOD\%$), фактический вес заполнения матрицы ($FW$, мг) для получения правильного сухого веса таблетки рассчитывается как:
- **Вес гранулята на таблетку с учетом влаги ($mg$):**
  $$W_{granules\_wet} = \frac{W_{tablet} \times \frac{Intra\%}{100}}{1 - \frac{LOD\%}{100}}$$
- **Итоговый вес заполнения ($FW$, $mg$):**
  $$FW = W_{granules\_wet} + W_{tablet} \times \frac{Extra\%}{100}$$

### 4. Расчет технологических потерь
- **Масса потерь серии ($kg$):**
  $$M_{loss} = M_{dry} \times \frac{Loss\%}{100}$$

## Настройки оборудования и размер копира (Fill Cam Size)

Расчет глубины заполнения матрицы ($FD_{theory}$, мм) на основе целевого веса таблетки ($W_{tablet}$, мг), насыпной плотности порошка ($\rho$, г/мл) и геометрии пуансонов.

### 1. Расчет площади сечения пуансона ($A$, $mm^2$)
- **Круглый пуансон:**
  $$A = \frac{\pi \cdot D^2}{4}$$
  где $D$ — диаметр пуансона в мм.
- **Фигурный / капсуловидный пуансон:**
  $$A = W_p \cdot (L - W_p) + \frac{\pi \cdot W_p^2}{4}$$
  где $L$ — длина в мм, $W_p$ — ширина в мм.

### 2. Расчет теоретической глубины заполнения ($FD_{theory}$, $mm$)
$$FD_{theory} = \frac{W_{tablet}}{\rho \cdot A}$$

### 3. Выбор копира заполнения (Fill Cam)
Поскольку таблетпресс работает по принципу избыточного наполнения:
- **Рекомендуемый размер копира ($mm$):**
  $$FD_{cam} = FD_{theory} + 3\text{ мм}$$
- Рекомендуется подбирать ближайший больший стандартный размер копира из ряда: `[4, 6, 8, 10, 12, 14, 16, 18, 20]`.

## Пресеты глубины заполнения для брендов прессов (Press Presets)

Расчет технологических пределов / настроек глубины заполнения ($FD$) по эмпирическим формулам производителей:

- **Fette Compacting:**
  $$FD_{Fette} = 2 \cdot Thickness + 2\text{ mm}$$
- **GEA Courtoy:**
  $$FD_{Courtoy} = 1.8 \cdot PCH$$
  где $PCH$ — высота предварительного прессования (Pre-compression Height, мм).
